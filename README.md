# ZONA Parts

Локален веб-шоп за една продавница за автоделови. React + TypeScript + Vite, со Node API.

## Стартување

Во два терминали:

```sh
node server/index.mjs
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

Отвори http://127.0.0.1:5174. Vite ги пренасочува `/api` барањата кон API на портата 4000.

```sh
npm run build
```

## Функции

- Единствен продавач: ZONA Parts.
- Каталог од API, категории, пребарување по име/бренд/каталошки број и сортирање по цена.
- Детали на производ и кошничка со количини, зачувана во localStorage.
- Достава или лично подигање и локална демо-нарачка.
- Серверска проверка на количини, цени и залиха; една доставна такса по нарачка.

## Демо-податоци

Производите, цените и залихата се примерни. Илустрациите се категоријални, а не фотографии од реалните производи. Каталогот и залихата се во меморија, а нарачките немаат трајно складирање или испраќање до продавницата. Рестарт на API ја ресетира залихата. PostgreSQL сè уште не е поврзан.

За јавно пуштање потребни се вистински каталог/фотографии, трајна база за производи и нарачки, податоци за продавницата и конечни услови за достава. Production hosting мора да ги проследува `/api` барањата до backend.

## Барања за понуда

Избор на возило за шест марки, пребарување по систем и слободно внесување кој било модел/дел. Барањата и подготвените понуди се зачувуваат трајно на локалниот диск. Клиентот добива приватен код за проверка и прифаќање на понудата. За работниот тек на сопственикот и поврзување вистински каталог види [docs/quote-catalog.md](docs/quote-catalog.md).

Овие листи се почетни и не претставуваат сите генерации и мотори. Целосен проверен каталог и автоматска компатибилност бараат податоци од добавувач. Барањата за понуда се одделни од постојните демо-нарачки на кошничката.
