# Пребарување возила, делови и понуди

## Што работи локално

- Шест марки: BMW, Mercedes-Benz, Audi, Volkswagen, SEAT, Porsche.
- Листи на серии, модели и изведби од јавните страници на mobile.de, дополнети со историските модели и претходните изведби. Не се исцрпен каталог на сите генерации, години и мотори.
- Рачно внесување кој било модел, генерација, мотор, година и опционален VIN. Нема ограничување само на моделите во почетната листа.
- Називи на делови во 12 системи, пребарување и додавање произволен дел или OEM број.
- Повеќе делови по барање, количина, нов/половен, каталошки број и напомена.
- Барањата се зачувуваат како приватни JSON датотеки во `server/data/quotes/` и преживуваат рестарт. Датотеките се игнорирани од Git. За друг директориум употреби `QUOTE_DATA_DIR`.
- Пристап преку број на барање и приватен случаен код. Серверот чува само SHA-256 hash од кодот. Нема јавно набројување на барања или контакти.
- Сопственикот внесува понуда од локален CLI. Клиентот ја проверува и прифаќа преку „Мои понуди“.
- Нема автоматски е-пошта/SMS, VIN декодирање, автоматска потврда на компатибилност или автоматска цена од добавувач. Прифатена понуда се зачувува како `ACCEPTED`; не одзема залиха и не наплаќа средства.

## Стартување

```sh
npm run api:start
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

`api:start` ја чита `.env` ако постои. API клучевите се поставуваат таму, никогаш во `VITE_*` променливи.

## Подготовка понуда од сопственикот

На компјутерот што го хостира backend, со пристап до датотеките:

```sh
node --env-file-if-exists=.env scripts/quotes.mjs list
node --env-file-if-exists=.env scripts/quotes.mjs show Q-REAL_ID
node --env-file-if-exists=.env scripts/quotes.mjs offer Q-REAL_ID 1200,3500 150 7 "Опис на деловите, рок за достава и услови"
```

`Q-REAL_ID` замени го со вистинскиот број. Цените одделени со запирка се единични цени во редоследот на деловите во барањето. Потребна е по една цена за секој дел. `150` е една доставна такса за целото барање, `7` е важноста во денови. CLI одбива промени на прифатена понуда. Тоа е локална административна алатка; нема неавтентицирана HTTP функција за внесување цени.

При промена на цени освежи ја понудата со „Провери“. Кодот не се испраќа преку е-пошта: клиентот го добива во сајтот и треба да го зачува. На истиот уред последните 20 кодови се зачувани во localStorage.

## Вистински целосен каталог

За проверено покривање се потребни податоци од TecDoc/TecAlliance или добавувач со право на користење. Јавните страници немаат доказ за целосно покривање на сите возила и мотори. „Сите делови“ преку рачно барање не значи дека секој дел е на залиха или дека секој дел е автоматски компатибилен.

Backend е подготвен за gateway со сопствен JSON договор. Не е имплементиран фиктивен TecDoc API протокол: вистинскиот TecDoc адаптер треба да се напише според документацијата и пристапот што ќе ги добиеш од добавувачот.

Постави во `.env`:

```dotenv
CATALOG_API_URL=https://your-supplier-gateway.example/catalog
CATALOG_API_TOKEN=your-server-side-token
```

Gateway треба да врати:

```json
{
  "source": "Име на вистинскиот добавувач",
  "exhaustive": false,
  "makes": {
    "BMW": ["3 Series"],
    "Mercedes-Benz": ["C-Class"],
    "Audi": ["A4"],
    "Volkswagen": ["Golf"],
    "SEAT": ["Leon"],
    "Porsche": ["911"]
  },
  "partGroups": [
    { "name": "Сопирачки", "parts": ["Кочиони дискови", "Кочиони плочки"] }
  ]
}
```

Ова е само пример на структурата, не целосен каталог. Двете јавни API рути `/api/v1/vehicles` и `/api/v1/part-groups` го користат gateway; пристапниот токен останува на серверот. Одговорот се кешира 15 минути. HTTPS е задолжителен освен за локален gateway. При грешка се враќа 503, а формуларот дозволува рачно внесување. `exhaustive: true` постави само кога податоците се навистина проверени за потребното покривање.

Цени, залиха и релации возило–дел не се дел од овој gateway договор; засега тие се проверуваат при рачна подготовка на понудата. За автоматизација треба дополнителен адаптер за конкретниот добавувач.

## Подмодели во полето „Модел“

По избор на марка, листата автоматски се отвора и ги прикажува сите модели и групирани подмодели што се во достапните податоци. Со пишување во истото поле се пребаруваат моделите и изведбите. Достапни се избор со стрелки/Enter и затворање со Escape. Полето овозможува рачен внес на модел што недостига. При промена на марка се чистат моделот, генерацијата и моторот.

Gateway може дополнително да врати `submodels`, со структура:

```json
{
  "submodels": {
    "BMW": { "3 Series": ["3 Series 320d", "3 Series 330i"] }
  }
}
```

Секоја моделска фамилија мора да постои во `makes` за истата марка. Ако добавувачот испрати целосни листи, сите записи ќе бидат прикажани; локалните подмодели се почетен избор, не сите можни мотори, каросерии и генерации. Не се генерираат непроверени комбинации мотор–генерација.

## mobile.de референца — 14.10.2026

Снимката `server/data/mobile-vehicles.json` содржи 151 серија и 486 записи за модели, каросерии и генерации од сите серии поврзани во шесте јавни страници за марки. Секој запис го чува URL-от на изворната серија и марка. BMW `3er` е прикажан како `3 Series`, Mercedes `C-Klasse` како `C-Class`, а германските називи за каросерии се преведени. Годините од јавните карти не се употребуваат за автоматска компатибилност.

Извори:

- https://www.mobile.de/auto/bmw/marke/
- https://www.mobile.de/auto/mercedes/marke/
- https://www.mobile.de/auto/audi/marke/
- https://www.mobile.de/auto/vw/marke/
- https://www.mobile.de/auto/seat/marke/
- https://www.mobile.de/auto/porsche/marke/

Достапни се сите записи во снимката, без ограничување на првите резултати. Изборот е групиран по серија и може да се пребарува по назив или код на генерација. Историските фамилии и претходните изведби се задржани.

Ова е локална снимка на прочитаните јавни водичи, без live синхронизација, врска со огласи или копирање цени на автомобили. Динамичната taxonomy-листа на пребарувањето не е преземена. `exhaustive` останува `false`; нема тврдење дека снимката ги содржи сите можни модели од сите пазари. Функцијата за понуди останува за автоделови од ZONA Parts.
